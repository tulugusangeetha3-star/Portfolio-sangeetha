# 🌐 Personal Portfolio Website

Welcome to my personal portfolio repository! This website showcases my background, skills, featured projects, certifications, and technical resume.


## 🚀 Features

- **About Me:** Overview of my academic background and career goals.
- **Skills:** Comprehensive breakdown of programming languages, tools, and technical domain knowledge.
- **Projects:** Showcase of hands-on technical projects and implementations.
- **Certifications & Resume:** Key course certifications and quick access to my updated resume.
- **Contact:** Links and contact channels to get in touch.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript
- **Assets & Docs:** PDF references and optimized project graphics
- **Hosting:** GitHub Pages
